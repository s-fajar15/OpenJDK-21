# 🛒 Tokped Scraper

Tokped Scraper adalah alat pencarian dan ekstraksi data produk dari Tokopedia yang powerful dan mudah digunakan.

## ✨ Fitur Utama

- 🔍 Pencarian produk real-time
- 📊 Ekstraksi data detail produk
- 🎨 Output yang informatif dan berwarna
- 🚀 Performa tinggi dan mudah digunakan

## 🛠️ Instalasi

1. Clone repositori ini:
   ```
   git clone https://github.com/username/tokped-scraper
   ```
2. Masuk ke direktori proyek:
   ```
   cd tokped-scraper
   ```
3. Install dependensi yang diperlukan:
   ```
   pip install -r requirements.txt
   ```

## 🚀 Cara Penggunaan

1. Jalankan skrip:
   ```
   python tokped_scraper.py
   ```
2. Masukkan kata kunci pencarian saat diminta.
3. Lihat hasil pencarian yang ditampilkan dengan indah di konsol Anda!

## 📋 Contoh Output

```
 # Store        : OfficialStore
 # Product      : Smartphone XYZ Pro
 # Harga        : 3.999.000
 # Discount     : 10%
 # Rating       : 4.8
 # Terjual      : 1000+
 # link product : https://www.tokopedia.com/product-xyz
```
